== Description ==

WP Documentation is a fast, lightweight, and fully responsive WordPress theme for creating documentation, knowledge base, user guides, FAQs, and support portals. Built specifically for Gutenberg, it offers a clean, distraction-free reading experience optimized for both desktop and mobile.

Whether you're building documentation for a SaaS product, WordPress plugin, software tool, API, or internal wiki, WP Documentation makes it easy — no coding required.

== Features ==

• **Blazing Fast Built-in Search**
  Instant, fuzzy search for docs, FAQs, and release notes.

• **Structured Documentation Hierarchy**
  Multi-level, collapsible sidebars and grid navigation for easy browsing.

• **Release Notes & Changelog Support**
  Dedicated templates for versioning and product updates.

• **FAQ System**
  Built-in FAQ post type and interactive layouts.

• **Multiple Layouts & Variants**
  Choose from various doc grid, card, and single page layouts (informative, minimal, stacked, etc.).

• **Responsive & Mobile-First Design**
  Fully adaptive layouts for all devices.

• **Light & Dark Mode**
  Automatic or manual color scheme switching.

• **Gutenberg-Ready**
  100% compatible with the WordPress block editor.

• **SEO Optimized**
  Semantic HTML, breadcrumbs, and clean markup for better search engine visibility.

• **Customizable Theme Options**
  Change colors, layouts, and more via the settings page code required.

• **Accessibility First**
  Keyboard navigation, ARIA labels, and screen reader support.

• **Performance Optimized**
  Minimal scripts, deferred loading, and optimized assets for fast page loads.

• **Essential Integrations**
  Works with Fast Fuzzy Search, Secure Custom Fields, Nested Pages, and Code Block Pro plugins.

• **Translation & RTL Ready**
  Fully localized and compatible with multilingual plugins.

• **Onboarding**
  Guided setup and onboarding for a quick start.

• **Pro Features (Upgrade)**
  Advanced layouts, priority support, and enhanced customization options.

== Installation ==
1. Upload the theme to the `/wp-content/themes/` directory or install it via the WordPress theme installer.
2. Activate the theme through the 'Appearance > Themes' menu in WordPress.
3. Configure theme options as needed in the WordPress Customizer.
